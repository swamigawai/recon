1. Executive Problem Statement: The Ingestion Bottleneck

In enterprise architectures, onboarding partner data feeds (CSV, TSV, JSON) remains a high-friction operational bottleneck:

  • The Ingestion Cycle: Integrating an unfamiliar partner feed typically requires multiple business days of developer discovery, manual script debugging, and schema clarification.
  • The Silent Drop Risk: When dirty data hits production warehouses, scripts frequently coerce nulls or drop failing rows via unlogged TRY_CAST logic, leading to financial ledger reconciliation discrepancies.
  • The Copilot Guessing Problem: Generic AI assistants hallucinate non-existent column names, invent surrogate keys, or drop unmapped mandatory fields to force code execution.

2. Strategic Solution: Deterministic Preflight Readiness

Recon is an Integration Compiler. Rather than permitting dirty data to reach runtime ingestion pipelines, Recon verifies partner data in a deterministic preflight sandbox before code deployment.

1. The 7-Stage Preflight Engine (MECE)

[01 INGEST] ──> [02 PROFILE] ──> [03 MAP] ──> [04 AUDIT] ──> [05 ADAPTER] ──> [06 VALIDATE] ──> [07 DOSSIER]
  • 01 Dual-Port Intake: Port 1 ingests raw CSV/JSON; automatically strips UTF-8 BOM headers (\xef\xbb\xbf) and detects root record envelopes. Port 2 ingests strict target contracts (OpenAPI 3.1, JSON Schema Draft-07).
  • 02 100% Columnar Profile: Scans 100% of cells without down-sampling. Computes cardinality, null ratios, and candidate types.
  • 03 Semantic Mapping: Proposes mappings using normalized exact matching, dot-notation suffix flattening, and domain synonym dictionaries (e.g. qty ↔ item_count).
  • 04 Risk Radar & Gate: Scans mappings against 8 deterministic rules (R001–R008). Enforces lead engineer sign-off.
  • 05 AST Adapter Workbench: Pure-Python Abstract Syntax Tree compiler generates standalone, reviewable PEP-8 scripts.
  • 06 Zero-Loss Validation Lab: Isolated sandbox runs adapter on 100% of rows. Produces valid vs. quarantine streams.
  • 07 Cryptographic Dossier: Packages adapter, valid payloads, quarantine diagnostics, and signed SHA-256 manifest.

2. Deterministic Risk Radar Rules (R001–R008)

RULE SEVERITY TRIGGER CONDITION ENGINE ACTION & RESOLUTION
R001 CRITICAL Target field marked required has no mapped source. HARD BLOCKER: Locks code generation until mapped or given a default constant.
R002 MEDIUM Incompatible data types (e.g., String to Integer). Synthesizes explicit type-casting logic in AST adapter with fallback catch block.
R003 HIGH Target is non-nullable, but source contains nulls. Emits warning; rows containing null values are routed to quarantine ledger.
R005 HIGH Source value outside contract enum domain. Emits warning; unlisted tokens (e.g. REFUND_PENDING) safely quarantined.
R006 LOW Leading or trailing dirty whitespace detected. Synthesizes automatic .strip() cleaning in generated adapter.

2. Production Runtime Deployment Topology

Recon generates a standalone, reviewable Python script (adapter.py) that embeds into any enterprise data plane:

  • Apache Airflow / Dagster DAGs: Valid stream loads directly to Snowflake staging; quarantine stream routes to a Dead Letter Queue (DLQ).
  • Serverless AWS Lambda / Google Cloud Run: Sub-millisecond cold starts executing micro-batch transformations with native Pydantic v2 Rust core.
  • FastAPI / Microservices: Synchronous inbound partner webhook validation.
